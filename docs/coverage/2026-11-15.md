## iOS

From an iOS simulator run of the `Winston` test plan through
`App/Winston.xcworkspace` on the same commit (iPhone 17, iOS 27.2; 553
passed, 4 skipped). There, coverage is reported per binary, and only some
libraries are binaries of their own; the rest are linked into the test
bundles, so there is no single `Sources/` total for iOS.

| Library | iOS lines | Covered | macOS lines | Covered |
|---|---|---|---|---|
| VoiceLoop | 3,641 | 88.6% | 3,508 | 88.1% |
| WinstonCore | 1,117 | 92.3% | 1,065 | 96.5% |
| WinstonLogging | 160 | 66.3% | 160 | 97.5% |

VoiceLoop and WinstonCore count more lines on iOS because of their
`#if os(iOS)` code. WinstonLogging is lower because its tests that need a
child process only run on macOS.

## Reproduce

```sh
Scripts/coverage.sh

xcodebuild test -workspace App/Winston.xcworkspace -scheme Winston \
  -destination "platform=iOS Simulator,name=iPhone 17" \
  -derivedDataPath DerivedData -resultBundlePath DerivedData/ios-tests.xcresult
xcrun xccov view --report --only-targets DerivedData/ios-tests.xcresult
```
